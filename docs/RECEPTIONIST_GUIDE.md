# 👩‍💼 دليل موظف الاستقبال (Receptionist User Guide)

> **المستخدم**: موظف/سيكريتارية العيادة (Staff)  
> **الهدف**: إدارة المواعيد اليومية والمرضى المباشرين بسهولة وسرعة.

---

## المهام الأساسية للاستقبال

### 1. تسجبل مريض مباشر في العيادة (Walk-in)
1. افتح صفحة **"جدول المواعيد"** (`/appointments`).
2. اضغط على **"+ حجز يدوي مباشر (Walk-in)"**.
3. أدخل اسم المريض الثلاثي، رقم الواتساب، التاريخ، والوقت.
4. اضغط **"حفظ الموعد"**.

### 2. البحث عن مريض بالاسم أو الموبايل
1. افتح صفحة **"سجل المرضى"** (`/patients`).
2. اكتب اسم المريض أو رقم هاتفه في مربع البحث العلوي.

### 3. طباعة جدول المواعيد اليومي للدكتور
1. افتح صفحة `/appointments`.
2. اضغط على زر **"طباعة الكشف"** لتجهيز النسخة المطبوعة لمكتب الدكتور.
