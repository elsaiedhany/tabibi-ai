## 3. إدارة الأطباء وحسابات العيادات

1. **إضافة طبيب جديد**:
   - اذهب إلى صفحة `/doctors` ➔ اضغط **"+ إضافة طبيب جديد"**.
   - أدخل اسم الطبيب، التخصص، ورقم الواتساب.
2. **إيقاف أو تفعيل طبيب**:
   - يمكنك تفعيل أو إيقاف حساب الطبيب بنقرة واحدة من لوحة Super Admin.
   - عند إيقاف الطبيب، يتم منع الدخول لحسابه فوراً وتتوقف أتمتة الواتساب الخاصة به مع الحفاظ على كافة بياناته السابقة.

## 4. التأكد من عزل بيانات الأطباء (Tenant Isolation)

- النظام يضمن برمجياً وعلى مستوى السيرفر عدم قدرة أي طبيب أو موظف استقبال على رؤية بيانات طبيب آخر.
- محاولة الوصول المباشر عبر المعرفات (IDOR) تُرجع تلقائياً خطأ `403 Forbidden`.
